## 1. 현재 메인 페이지를 따라가며 확인할 내용

| 장면 | 반영된 내용 |

## 2. 배 섹션 최종 연출

**메인 타이틀은 아래에서 위로, 세부 항목은 좌우 바깥에서 배 쪽으로** 움직입니다. 중간 배포본에는 세부 항목도 아래에서 올라오는 연출이 있으므로 재작업 시 최신 커밋을 기준으로 보세요.

1. 도로가 사라지고 화면 중앙의 갑판 폭이 화면 너비의 약 ⅛이 되면, 타이틀과 도입 본문이 화면 하단에서 올라옵니다. 스크롤을 이어가면 중간 정지 없이 위로 지나갑니다.
2. 왼쪽 항목은 오른쪽으로, 오른쪽 항목은 왼쪽으로 이동해 배 양옆에 붙습니다. 각 항목에서 **아이콘 → 소제목 → 설명** 순으로 들어오고, 오른쪽은 왼쪽보다 조금 늦게 시작합니다. 이 간격은 스크롤 진행량을 기준으로 하므로 휠을 멈추면 모션도 멈춥니다.
3. 공간이 충분하면 두 쌍을 위·아래 두 줄에 배치합니다. 화면 높이가 부족하면 첫 번째 쌍과 두 번째 쌍이 같은 높이에 순서대로 나타납니다. 마지막 탄소 절감 항목은 하단 중앙에서 서서히 나타납니다.

## 4. 확인 범위와 남은 항목

- **배포 확인** — 마지막 좌우 모션 버전은 스크립트 문법 검사와 공개 사이트의 변경 코드 응답을 확인했습니다. 앞선 버전에서는 브라우저로 타이틀 진입 위치를 측정했습니다. 마지막 좌우 모션의 데스크톱·모바일 실제 재생 대조는 남아 있습니다. 특히 낮은 화면에서 두 쌍이 교대할 때 설명을 읽을 시간이 충분한지 확인하면 됩니다.
- **리치스태커** — 실시간 3D 시안은 `proto/reachstacker.html`에 있습니다. 기존 인수인계에 적힌 새 모델의 140프레임 재렌더 교체는 완료 확인 전입니다. 트럭 모델도 교체한다면 뒤에 이어지는 트럭 측면·탑뷰 이미지의 연결을 함께 확인해야 합니다.
- **기존 보류 사항** — 헤더 메뉴 개편과 컨베이어 주변 사람 모션은 미결입니다. 비행기 뒤 서비스 장면(`svpScene`), 노란 배송 완료 상자(`delivSec`), 미니게임 소개(`crewScene`), 사용자 유형별 안내(`whoSec`), 예전 바로가기·고객센터는 숨김 상태입니다. 게임은 푸터 이스터에그로 접근합니다.
